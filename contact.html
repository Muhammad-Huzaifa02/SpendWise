COMMON QUESTIONS

Frequently Asked Questions

Some useful information about the SpendWise project.

What is SpendWise?

SpendWise is a personal expense management website designed to help users organize expenses, plan budgets, and track savings.

Does SpendWise use Pakistani Rupees?

Yes. The project uses PKR (Rs.) as its currency and includes categories relevant to everyday expenses in Pakistan.

Can I save my expenses?

The current Phase 1 prototype is static. Expense storage and management functionality will be introduced in a later development phase.

Can I use SpendWise on mobile?

The website layout is designed to adapt to different screen sizes, including desktop, tablet, and mobile.
